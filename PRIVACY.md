# Privacy Policy — Reverse Search

Effective date: October 13, 2026

Reverse Search changes the value of a supported search field locally in your browser immediately before that search is submitted. It can also open a reversed Google search when the user deliberately uses the extension popup or the `reverse` address-bar keyword.

The extension does not collect, transmit to the publisher, sell, share, or retain personal information. It does not use analytics, cookies, remote code, a server, or browser storage. When the user deliberately searches through the popup or `reverse` address-bar keyword, the reversed query is sent to Google to provide that search. When the user uses a supported search-engine page, the revised query is sent only to that search engine.

The extension is active only on the search-engine domains listed in its manifest. It does not run on other websites.

For privacy questions, contact the publisher through the contact address shown in the Chrome Web Store listing.

Reverse Search uses user data only to provide its disclosed search-reversal feature. It does not use or transfer user data for advertising, profiling, sale to data brokers, or human review.
