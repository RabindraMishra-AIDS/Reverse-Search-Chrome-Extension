Privacy Policy — Reverse Search

Effective date: October 13, 2026

What Reverse Search does

Reverse Search reverses a search query locally in your browser. It can do this on supported search-engine pages and when the user deliberately uses the extension popup or the reverse address-bar keyword.

Data handling

The extension temporarily processes the text in a user-submitted search field solely to reverse that text. It does not store, collect, transmit to the publisher, sell, or share personal information. It does not use analytics, cookies, remote code, a server, or browser storage.

When the user searches through the popup or reverse address-bar keyword, the reversed query is sent to Google to provide that requested search. When the user uses a supported search-engine page, the revised query is sent only to that search engine.

Permissions

The extension runs only on the search-engine domains listed in its Chrome extension manifest. It does not run on other websites.

Limited use

Reverse Search uses user data only to provide its disclosed search-reversal feature. It does not use or transfer user data for advertising, profiling, sale to data brokers, or human review.

Contact

For privacy questions, contact the publisher through the contact address shown in the Chrome Web Store listing.
